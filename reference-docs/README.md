# Porting reference snapshots

[The UE3 porting research](../UE3_Xbox360_Switch_References.md) summarizes the evidence and its implications for War for Cybertron. The snapshots below were retrieved on 18 November 2026. They contain selected documents from the port authors. Relative links may require opening the original project. Each `SOURCE.txt` records the upstream URL and the branch commit observed after retrieval.

- [Singularity](singularity-nx/README.md) covers UE3 runtime, rendering, and performance fixes.
- [Gears of War 2](gears2-nx/README.md) describes the Switch UE3 toolchain and graphics stack.
- [Alice: Madness Returns](alice-nx/README.md) documents the renderer, visual differences, and CPU limits.
- [Mass Effect](masseffect-nx/README.md) has notes on [shaders](masseffect-nx/docs/shaders.md), [optimization](masseffect-nx/docs/optimization-paths.md), and [known issues](masseffect-nx/docs/known-issues.md).
- [Mortal Kombat 9](mk9-nx/README.md) has detailed [porting notes](mk9-nx/docs/mk9-notes.md).
- [Sonic Adventure 2](sa2-nx/README.md) provides a general Xbox 360 [porting guide](sa2-nx/docs/porting-guide.md) and [deko3d renderer guide](sa2-nx/docs/deko3d-renderer-guide.md). Its engine differs from UE3.

Licenses and notices are preserved with each upstream project's files.
